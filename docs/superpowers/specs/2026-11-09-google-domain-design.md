# Googleログインの新規ドメイン制限

ユーザー指定：新規のGoogleログインはメールのドメインがedu.kimura.ac.jpのアカウントのみ許可する。追加確認への回答により、既存アカウントは他ドメインでも例外としてログインを継続する。

既存アカウントはアプリのusersに登録済みの本人を、既存の認証IDまたはメールアドレスによる照合で判定する。既存の紐付け競合・無効・削除状態の判定を維持する。新規作成直前に、Supabaseで取得した本人のemailを使って完全一致のドメインを検査する。サブドメイン、似た末尾、メタデータの自己申告は許可しない。

方式：Google側のアカウント選択へのドメイン指定では既存の別ドメインも選べなくなるため、アプリの登録入口で既存を先に照合する。許可されない新規はアプリ利用者を作らず、OAuthから戻った現在のセッションだけを終了し、ログイン画面に理由を出す。通常のgetCurrentUserによる自動作成にも同じ判定を適用する。拒否後にセッションが残る場合もログイン画面との往復を防ぐため、ログイン済みの転送はアプリ本人確認後に行う。

新規登録の条件と既存利用者の例外をログイン画面に表示する。教師の共通アカウント・Google選択画面・既存データ・DBスキーマ・パッケージは変更しない。本番へのpushは本件の検証後に別途指示を受ける。

確認：新規の許可/拒否、既存の別ドメインと未紐付けメール、アカウント競合、既存情報の保持、通常の本人取得、OAuth戻り先・失敗・ログアウト失敗、拒否時の画面、教師ログイン、型・lint・ビルドを確認する。
