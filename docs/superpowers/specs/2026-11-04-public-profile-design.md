# 閲覧用プロフィール
ユーザー承認：ランキングのボタンを廃止し、名前・アイコンから掲示板とは独立したプロフィールを開く。戻ると元のランキングの試験・対象月に戻る。表示内容は既存の名前・アイコン・装備称号・自己紹介・投稿一覧を引き継ぐ（2026-11-04の回答）。
方式：掲示板プロフィールの戻り先だけを直す案は、独立した画面という依頼を満たさないため採用しない。既存の公開内容と操作を共通コンポーネントに移し、/users/[userId] を正規の閲覧画面にする。
自分の編集用 /profile は維持。既存の /board/users/[userId] は互換のため新画面へ誘導する。ログイン必須、停止・退会済み利用者は非公開、教師の既存表示・操作権限を維持。
戻り先は内部のランキング・掲示板・投稿詳細だけを許可し、任意URLへの遷移を防ぐ。表示は既存の配色・カード・アバターを使用する。
パッケージ・本番データは変更しない。学習成績・ポイント・メール等の公開項目は増やさない。

追加承認（2026-11-04）：掲示板投稿欄の本人アイコンを専用画面へのリンクにする。バナーの色を本人が選んで保存する。称号をマイページと同じ名前横・丸いハイライトにする。バナーはマイページと公開画面に表示し、本人だけ編集可能。保存のためstudent_profilesへbanner_color（6桁HEX、既定#deece6）を1列追加する。本番適用は別途反映時に行う。

追記承認：称号ハイライトの背景色は保存したバナー色と同じにする。任意の明度に対して称号文字は黒／白のコントラストが高い方を選ぶ。
