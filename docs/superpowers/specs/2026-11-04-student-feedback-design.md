# 利用者フィードバックへの対応

最終要件：模擬試験の回答選択を即座に表示する。通知一覧を開いたら、その時点の未読を全部既読にする（ユーザー回答）。復習ノートにもAI解説を追加する。ログイン画面の色変更はユーザーの追加指示により取り消し、元の表示を維持する。

方式：模擬試験は確認済みの回答に保存中の選択を重ね、保存順序・エラー時の保護・提出前flushを維持する。通知は画面の実マウントから本人の一括既読APIを呼び、先読みで既読にしない。アカウント切り替えと開き直しの基準時刻を分離する。AIは回答保存後に既存の画像対応生成・キャッシュを共用する。

公開・個人情報・役割・得点・試験期限・採点・ポイントの仕様を維持する。AIを模擬試験の受験中に追加しない。DBスキーマ、パッケージ、外部設定は変更しない。

検証：遅延した保存応答より先に選択が変わること、連続選択の巻き戻りなし、障害・再試行・期限・提出、本人だけの既読化・新着の保持・先読みでの未更新・アカウント切り替え、AIの所有・回答済み・版・未公開問題チェック・再試行・画像・失敗を確認する。PC・スマホで実操作し、取り消したログイン配色の差分がないことも確認する。

公開の承認：ローカルでの結果報告後、ユーザーの「push」により、この3機能をGitHub mainへ反映し、Vercelの自動デプロイを確認する。
